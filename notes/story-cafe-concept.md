# 故事咖啡馆 · Story Café

## 产品概念

一家开在剑与魔法世界里的咖啡馆。你是店员。每天有不同的人推门进来，给你讲一个故事——你只需要听、追问、然后选择要不要相信他们。

这不是英语课。这是**一个活着的世界**。

## 核心循环

```
Day 1
  一个客人推门进来 → 带来一个八卦/故事 → 你选择"去"还是"不去"
Day 3
  另一个客人带来后续 → "上次那个人死了/发财了/失踪了"
Day 7
  第一个客人回来 → 带来结局
```

## 三层体验

- **☕ 聆听** — 角色演给你听，你只需要选"然后呢？"
- **🎤 对话** — 你开口追问，影响故事走向
- **🎬 配音** — 你化身角色演一段，AI 从发音/情感/节奏三个维度评分（不给好评，要对抗）

## 第一个故事线

**背景：** 东边矿井挖出了不该挖的东西。
**角色：** 矮人矿工（第一个客人）、老常客（情报源）、学徒（信使）。
**结构：** 开场（氛围）→ 故事入门 → 选择分支 → 后续发展。

## 产品哲学

故事咖啡馆的核心理念是——用户不是为了"学英语"留下来，而是为了"想知道然后呢"留下来。语言是在这个过程中自然习得的副产品，不是目标。
